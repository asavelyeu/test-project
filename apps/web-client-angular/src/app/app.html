Empty State (NGI-16 · data=[])

When data is an empty array, a placeholder with icon and message is shown. Column headers remain visible.

Loading State (NGI-16 · loading=true)

When loading is true, a shimmer skeleton is shown — clearly distinct from the empty state. Click the button to simulate a 2-second data fetch.

Cell Types (NGI-19 through NGI-30)

Each table below highlights a pair of related cell types.

Text & Number (NGI-19 · NGI-20)

Text truncates with ellipsis. Numbers are right-aligned with tabular-nums.

Date & Currency (NGI-21 · NGI-22)

Dates render as DD MMM YYYY. Currency uses Intl.NumberFormat with locale.

Status Badge & Progress (NGI-23 · NGI-24)

Badges are color-coded chips. Progress shows a horizontal bar with percentage label.

Avatar & Link (NGI-25 · NGI-26)

Avatar shows circular initials + name. Links are clickable anchors with target=_blank.

Boolean & Icon+Text (NGI-27 · NGI-28)

Boolean renders ✓/✗ icons or Yes/No text. Icon+Text places an icon alongside text.

Multiline & Tags (NGI-29 · NGI-30)

Multiline wraps and clamps with -webkit-line-clamp. Tags render as styled chips.
